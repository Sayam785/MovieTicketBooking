# Movie Ticket Booking System

A menu-driven C++ console application developed for the B.Tech CSE Semester 5 System Design assignment.

## Features

- List currently playing movies
- View movie shows and screens
- Display seat availability
- Book one or more seats
- Seat-based pricing:
  - Silver: ₹150
  - Gold: ₹250
  - Platinum: ₹400
- Payment through UPI, Card, or Cash
- Generate and print tickets
- Cancel bookings
- Handle failed payments and invalid inputs
